# Skins próprias

PNG 64×64, layout padrão de skin Minecraft Java, braços clássicos de 4 pixels (modelo Steve), com camadas externas transparentes. Nico verde-água e Lia lavanda. Criadas por código neste projeto; não são skins oficiais nem assets extraídos do jogo. `*-preview.png` amplia o atlas por vizinho mais próximo. O filme usa as proporções 8×8×8 cabeça, 8×12×4 tronco, 4×12×4 em cada braço e perna. Texturas do cenário também são originais, 16×16, filtro nearest.
