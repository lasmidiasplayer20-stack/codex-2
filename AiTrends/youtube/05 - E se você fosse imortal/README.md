O PNG gerado ficou em área de trabalho; a capa entregue é JPEG 1280×720.

A primeira capa e seus arquivos de geração/metadados foram preservados em `historico/`; não executar o script antigo para recriar a capa atual. Os metadados de leitura atuais ficam somente em `YOUTUBE`.
